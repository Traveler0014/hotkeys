# AutoHotkey 热键脚本

一套可直接分享的 Windows 快捷键脚本，AutoHotkey **v2.0+**（在 2.0.31 上验证）。
以 [MIT 许可](LICENSE) 开源，可自由使用、修改、分发。

功能：常用程序一键启动、当前窗口置顶切换、服务器/设备上线闹钟。
设计目标：**一份代码换台电脑就能用**——内置默认值全部是 Windows 10/11 自带工具，
个人偏好（自己的终端、编辑器、文件管理器等）通过本机配置文件覆盖，无需改代码。

## 热键一览

| 热键 | 默认动作 | 说明 |
| --- | --- | --- |
| `Ctrl+Alt+T` | 终端（Windows Terminal） | 未安装 Terminal 时可在设置里改成 `cmd.exe` |
| `Win+E` | 资源管理器 | |
| `Ctrl+Alt+P` | 任务管理器 | 已在运行则激活已有窗口 |
| `Ctrl+Alt+E` | 记事本 | |
| `Alt+T` | — | 当前窗口 置顶 / 取消置顶 |
| `Alt+N` | — | 上线闹钟（多目标、可随时停止） |

上表是「内置默认」；实际生效的热键由 `hotkeys.ini` 决定，可在托盘菜单「热键设置」里改。
把自己的终端、编辑器指过去，只需要在设置窗口里改一行程序路径。

托盘图标右键菜单：热键设置、上线闹钟、停止全部监控、暂停所有热键、重新加载脚本、编辑脚本/默认配置、打开日志目录、退出。
鼠标悬停托盘图标可看到「已就绪 / 监控中 N 个 / 已暂停」。

## 配置分三层

| 层 | 文件 | 作用 | 是否入库 |
| --- | --- | --- | --- |
| 1 | `lib\Config.ahk` | 内置默认值（Windows 自带工具），开箱即用 | 是 |
| 2 | `hotkeys.ini` | 本机覆盖：自己的工具、工作目录、闹钟参数 | 否（`.gitignore`） |
| 3 | 托盘菜单「热键设置」 | 图形界面改第 2 层，保存后自动重载 | — |

- `hotkeys.ini` 存在时**以它为准**（`[apps]` 列表整体替换默认列表）。
- 删掉 `hotkeys.ini` 就回到内置默认配置。
- 分享给别人：给整个目录（去掉 `hotkeys.ini`、`logs\`、`hotkeys.exe`），对方双击 `hotkeys.ahk` 即可。

## 热键设置窗口

托盘菜单 →「热键设置」：

- 列表：`热键 / 说明 / 程序`，可 **添加 / 编辑 / 删除 / 上移 / 下移 / 恢复默认**（双击行 = 编辑）。
- 添加时填：热键（如 `^!t`）、说明、程序路径（可点「浏览…」）、启动参数、工作目录、是否「已在运行时激活窗口」。
- 保存时会校验热键写法与重复，然后写 `hotkeys.ini` 并自动重载脚本。

热键写法：`^`=Ctrl，`!`=Alt，`+`=Shift，`#`=Win，可组合。例：`^!t` = Ctrl+Alt+T，`#e` = Win+E，`!F2` = Alt+F2。

也可以手工编辑 `hotkeys.ini`（UTF-8 纯文本，格式见 `hotkeys.ini.example`），
改完用托盘菜单「重新加载脚本」生效。

## 目录结构

```
hotkeys\
├─ hotkeys.ahk          入口：全局设置 + 托盘菜单 + 启动初始化
├─ hotkeys.ini          ★ 本机配置（GUI 生成，不入库）
├─ hotkeys.ini.example  配置格式示例
├─ lib\
│  ├─ Config.ahk        内置默认值：CFG（通用参数）+ APPS_DEFAULT（默认启动器）
│  ├─ Settings.ahk      UTF-8 INI 读写 + 热键设置窗口
│  ├─ Util.ahk          日志 / 托盘提示 / 启动进程 / 错误兜底
│  ├─ Launcher.ahk      启动器热键（由 APPS 表驱动）
│  ├─ WindowTools.ahk   Alt+T 窗口置顶
│  └─ NetAlarm.ahk      Alt+N 上线闹钟
├─ assets\              图标（编译 exe 用，可自行替换）
├─ logs\                运行日志，按天分文件（自动生成，不入库）
└─ hotkeys.exe          编译产物（不入库）
```

## 上线闹钟（Alt+N）

- 一个输入框可填多个目标（空格或逗号分隔），支持 IP 和域名；目标做字符白名单校验，不会拼出危险的命令行。
- 每个目标独立监控、独立停止；列表里能看到状态（探测中/未上线/已上线）和探测次数。
- 命中时：托盘气泡 + 蜂鸣（次数可配）；可选额外弹窗（默认关，因为弹窗会阻塞脚本）。
- 关掉窗口不影响监控（托盘提示显示「监控中 N 个」），托盘菜单可一键「停止全部监控」。

## 编译成 exe（可选）

```bat
"C:\Program Files\AutoHotkey\Compiler\Ahk2Exe.exe" ^
  /in hotkeys.ahk /out hotkeys.exe /icon assets\icon.ico
```

`#Include lib\...` 是相对路径，编译时按 `hotkeys.ahk` 所在目录解析；exe 里会内嵌所有 include 内容，
因此改代码后需要重新编译（`hotkeys.ini` 是运行时读取的，不用重编译）。日常调参建议直接跑 `.ahk`。

开机自启：把 `hotkeys.ahk`（或 exe）的快捷方式放进 `shell:startup`。

## 排错

| 现象 | 排查 |
| --- | --- |
| 热键全部失效 | 托盘图标是否还在；被「暂停所有热键」挂起时菜单项有勾选 |
| 某个启动热键无效 | 看 `logs\` 当天日志里的 `跳过热键（程序不存在）`，在「热键设置」里修路径 |
| 脚本报错 | 日志里有 `未捕获错误 ...`（含文件与行号）；脚本不会因此退出 |
| 想看当前状态 | 鼠标悬停托盘图标 |

日志：`logs\yyyyMMdd.log`（UTF-8）。

## 实现说明（踩过的坑）

- **热键统一用 `Hotkey()` 动态注册**（各模块的 `*_Register()`），入口文件没有 `^!t::` 这类热键块，
  这样自动执行段不受「热键定义会截断自动执行段」的规则影响，也便于按配置决定是否注册。
- **闹钟完全非阻塞**：`ping` 用 `Run()` 异步发起，由 ping 自己写「成功/失败」标记文件，
  另一个 250ms 的收集器轮询结果；主线程不会被 `RunWait` 卡住。
  这里刻意**不用 PID 跟踪进程**——某些环境（安全软件拦截、部分 AHK 构建）下 `Run()` 返回空 PID，不可靠。
- **不用 `IniRead`/`IniWrite`**：它们和 UTF-16 绑定，手改或跨机器分享容易乱码，改为自带的 UTF-8 INI 读写。
- **字符串里不要出现「空格 + 分号」**：AutoHotkey 会把 `" ;"` 当作注释起点（即使在引号内），
  导致 `Missing "` 一类的语法错误。
- 程序路径缺失、热键注册失败、运行时异常都会写日志 + 托盘提示，不会静默失败。
- `ListView.Add('', 第一列…)` 的第二个参数是**第一列文本**，不是「表头占位」；写错会让整行右移一列。
